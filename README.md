This repository brings together practical projects created while building my JavaScript and web-development skills. The projects range from foundational HTML and CSS pages to interactive applications using DOM manipulation, browser storage, API requests, and object-oriented programming.

Throughout this journey, I have applied concepts such as:

- Object-oriented programming with classes and modules

## ▶️ Running a Project Locally

Most projects are static websites. Clone this repository and open the selected `index.html` file in a browser, or run it with the **Live Server** extension in VS Code.

Projects that load local JSON files or use APIs, such as the Medical Appointment Manager and Weather App, should be run through a local server rather than opened directly from the file system.
