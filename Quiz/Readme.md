# Quiz de Múltipla Escolha

Estrutura pronta (HTML + CSS). Falta a lógica em `script.js`.

## O que já está pronto
- Layout completo e estilizado (card, opções, tela de resultado)
- Array de 5 perguntas com respostas (`questions`)
- Referências do DOM
- Eventos já conectados aos botões

## O que você precisa implementar (em `script.js`)
1. `renderQuestion()` — mostrar a pergunta atual e suas opções na tela
2. `selectOption(index)` — marcar a opção escolhida
3. `checkAnswer()` — verificar se a resposta está certa e atualizar o placar
4. `nextQuestion()` — avançar para a próxima pergunta ou mostrar o resultado
5. `showResult()` — exibir a tela final com a pontuação
6. `restartQuiz()` — resetar o estado e recomeçar

## Como testar
Abra o `index.html` no navegador (ou use a extensão Live Server).
